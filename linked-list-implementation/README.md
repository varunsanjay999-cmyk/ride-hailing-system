Linked List Implementation

This folder contains the linked-list-based implementation of the Ride Hailing System, written in C.

Overview

A console-based application that manages drivers, passengers, ride bookings, and ride history using linked lists.

Technologies Used

- C Programming
- Linked Lists
- Data Structures and Algorithms

Compilation

Compile the source file using GCC:

gcc ride_booking_linked_list.c -o ride_booking_linked_list -lm

Run the program:

./ride_booking_linked_list

Note: Update the source filename in the compilation command if your actual filename differs.
