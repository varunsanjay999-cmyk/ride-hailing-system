AVL Tree Implementation

This folder contains the AVL tree-based implementation of the Ride Hailing System, written in C.

Overview

A console-based application that manages ride bookings, drivers, and passengers using data structures and algorithms.

Technologies Used

- C Programming
- AVL Trees
- Data Structures and Algorithms

Compilation

Compile the source file using GCC:

gcc ride_hailing_system.c -o ride_hailing_system

Run the program:

./ride_hailing_system

Note: Update the source filename in the compilation command if your actual filename differs.
