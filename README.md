Ride Hailing System

A console-based ride hailing system implemented in C, demonstrating the practical application of data structures and algorithms.

Project Overview

This project manages drivers, passengers, ride bookings, driver availability, and ride history through a menu-driven interface.

The system has two implementations using different data structures.

Implementations

1. AVL Tree Implementation

- Uses AVL trees for efficient, balanced data organization.
- Demonstrates tree operations and their application in a ride management system.
- Source code: "avl-implementation/"

2. Linked List Implementation

- Uses linked lists to manage drivers, passengers, and bookings.
- Demonstrates dynamic memory allocation and linked-list operations.
- Source code: "linked-list-implementation/"

Technologies Used

- C Programming
- Data Structures and Algorithms
- AVL Trees
- Linked Lists
- GCC Compiler

Learning Objectives

- Apply data structures to a practical problem.
- Understand the differences between tree-based and linked-list-based implementations.
- Practice memory management and modular program organization.
